# Call coaching

Turn one Zell call into clear coaching moments and a next drill.

## Steps

1. Confirm Zell is connected.
2. Resolve the call the user means (by name, date, prospect, or recent list) using Zell tools.
3. Summarize the coaching moments Zell already found: missed moments, skills, and suggested practice.
4. Offer one short drill tied to the highest-impact gap.
5. For managers, link that call back to who else on the team shares the same skill gap when Zell data supports it.

## Rules

- Quote or paraphrase Zell’s evidence; never fabricate transcript lines.
- Prefer the next practice action over a long transcript dump.
