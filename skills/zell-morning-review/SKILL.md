# Morning review for reps

Help the rep finish a short, focused morning review from Zell.

## Steps

1. Confirm Zell is connected; if not, run the getting-started connect flow.
2. Load the rep’s pending morning review / focus skill / drill from Zell tools.
3. Walk them through in order: what happened on the call, the one skill to practice, then the short drill.
4. Keep it to about five minutes of guidance. Do not dump every call score.
5. When the drill is done, confirm completion in Zell if a tool exists; otherwise tell them how to mark it done in the Zell app.

## Rules

- One focus skill at a time.
- Ground every tip in Zell’s call evidence; do not invent snippets or scores.
