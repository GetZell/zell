# Coaching priorities for managers

Help the manager decide **who to coach next** from real Zell call evidence.

## Steps

1. Confirm Zell is connected; if not, run the getting-started connect flow.
2. Use Zell MCP tools to load coaching priorities / team signals for the manager’s workspace.
3. Present **2–5 concrete priorities**. For each: rep name, skill or behavior to fix, and the call or evidence Zell cites.
4. Offer one next action: open that rep’s morning drill, review the call snippet, or assign a coaching task—only via Zell tools when available.
5. If the workspace has no priorities, say so plainly and ask whether calls are importing (Gong, Teams, tl;dv) or if they want help with scorecards.

## Tone

Be specific and actionable. Prefer “Coach Maya on discovery opener from Tuesday’s Pack demo” over “some reps need coaching.”
